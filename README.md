#### Sistema de Gestão escolar
Este programa é o projeto final do módulo 7 da disciplina Programação e Sistemas de Informação.

## Descrição
o programa é um sistema de gestão escolar, que tem várias funcionalidades, e os dados com a informação do programa ficam guardados em ficheiros .csv.

## Funcionalidades
- Adicionar alunos e disciplinas
- Inscrever alunos em disciplinas
- Eliminar alunos, disciplinas e inscrições
- Procurar aluno, disciplina e inscrição
- Ver estatísticas dos dados do programa

### Ficheiros OBRIGATÓRIOS

# Programa/código
- M7_projeto.cpp -> Código do programa
- M7_projeto.exe -> Executável no terminal

# Ficheiros com os dados
- ficheiro_alunos.csv -> guarda a informação dos alunos (nome, data nascimento, ID aluno)
- ficheiro_disciplinas.csv -> guarda a informação das disciplinas (nome, professor, ID disciplina)
- ficheiro_inscricoes.csv -> guarda a informação das inscrições (ID aluno, ID disciplina, nota final)
